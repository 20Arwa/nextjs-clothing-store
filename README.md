# 👚Clothes store

A modern e-commerce web application built with **Next.js** for selling clothes.  
It was created by following the YouTube tutorial:  
[Build and Deploy an Ecommerce Website with NextJS 15, Stripe, TailwindCSS](https://youtube.com/watch?v=DLeAPn5-TIA&si=VMyOZiyJw9jLHG_K).  

This project is for learning purposes.

---

## 🌐 Live Demo
👉 [View Live on Vercel](https://nextjs-clothing-store-gilt.vercel.app/)

---

## ✨ Features

- Browse different clothing products  
- Product carousel in the home page  
- Search by name and description  
- Filter products by category and gender  
- Clear all filters and search button  
- Shopping cart functionality:
  - Add items
  - Remove items
  - Update quantity
  - Clear cart
- Stripe checkout integration  
- Fully responsive design  
- Accessible UI  
- Clean and modern layout

## 🚀 Getting Started (Run Locally)

1. Clone the repository
    ```bash
    git clone https://github.com/20Arwa/nextjs-clothing-store.git
    cd nextjs-clothing-store
    ````

2. Install dependencies
    ```bash
    npm install
    ```

3. Create `.env`
    ```env
    STRIPE_SECRET_KEY=your_stripe_secret_key
    NEXT_PUBLIC_BASE_URL=http://localhost:3000
    ```

4. Run the development server
    ```bash
    npm run dev
    ```

5. Open: [http://localhost:3000](http://localhost:3000)
